If we want to use certain product in the Sales catalog with the sencondary unit:
- Set a default secondary unit for sales in product form.
- When catalog is loaded, the unit used will be this unit, rather than primary
  unit or previously selected secondary unit, if sale line already exists.

For a product that has no default secondary unit defined in its form:
- Catalog will operate as default, using primary unit.
- Secondary unit information filled for those sales lines taht already exist
  will be ignored, but preserved in later calculations.
