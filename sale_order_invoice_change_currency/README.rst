Adds support for manual currency rate from sales order to invoice.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Create a Sales Order and change it to new currency.
2. Once confirmed, and belonging to Invoice Managers, check "Apply Custom Currency Rate" and change the default rate, if needed.
3. Create an invoice. It will be created in the same order currency, with the new currency rate applied to journal items, instead of default one.
