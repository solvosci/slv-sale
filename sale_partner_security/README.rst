Limit which contacts an Odoo user can see based on the sales
representative assigned to that contact and the different permissions in
Sales for the Odoo user.

- User: Own Documents Only: they can see the contacts they are
  salespeople for, followers, or the contact they themselves are and
  view all contacts associated with Odoo users.
- User: All Documents: see all contacts
